HOW TO OPEN beam_d ON WINDOWS
================================

FIRST TIME ONLY
1. Install Python 3.10 or newer from python.org.
2. During Python installation, select "Add Python to PATH".
3. Download this GitHub branch as a ZIP file.
4. Extract the ZIP file. Do not run the program while it is still inside the ZIP.

OPEN THE PROGRAM
1. Double-click OPEN_BEAM_D.bat.
2. On the first run, wait while the required packages are installed.
3. beam_d will open automatically in your default web browser.
4. Keep the black launcher window open while using beam_d.
5. Close the black launcher window when you want to stop the program.

WINDOWS SECURITY MESSAGE
If Windows displays a SmartScreen warning:
1. Click "More info".
2. Confirm that the file name is OPEN_BEAM_D.bat.
3. Click "Run anyway" only when the file came from your own beam_d repository.

TROUBLESHOOTING
- Extract the downloaded ZIP before opening the launcher.
- Confirm that the computer is connected to the internet on the first run.
- Confirm that Python 3.10 or newer is installed.
- Do not delete the .venv folder after the first successful launch; it makes later launches faster.
